# SCpubr Reference Manual

This repository contains the source for the documentation book of [SCpubr](https://github.com/enblacar/SCpubr), an R package for publication-ready single-cell visualizations.

## Structure

- **Getting started**: Installation, dataset, quickstart, shared features
- **Function reference**: All SCpubr functions, grouped by analysis type
- **Workflows**: End-to-end analysis examples
- **Reference & Appendix**: FAQ, troubleshooting, citation, and more

## Building the Book

To render the book locally, you need [Quarto](https://quarto.org/) and R with all dependencies installed:

```sh
quarto preview
```

Or build static HTML:

```sh
quarto render
```
